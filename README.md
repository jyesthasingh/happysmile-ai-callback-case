# HappySmile: AI callback, two-screen mockup

A product case exercise (fictional scenario): a dental clinic chain wants to reach every online enquiry within minutes with an AI voice assistant.

- **Screen 1:** the moment a person asks to be contacted (patient, mobile).
- **Screen 2:** what the front desk sees afterwards (clinic dashboard with handovers).

All names, numbers and clinic data are fictional sample data.

Live page: https://jyesthasingh.github.io/happysmile-ai-callback-case/
